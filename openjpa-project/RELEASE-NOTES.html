Overview

This is the release of Apache OpenJPA 4.2.0. This distribution implements the Jakarta Persistence 3.2 specification. The Jakarta Persistence 3.2 TCK is run weekly in CI on Java 21 against PostgreSQL, MySQL, MariaDB, Microsoft SQL Server, Oracle and Apache Derby (on MySQL without the SEQUENCE tests, as MySQL has no sequences).

Additional information on the OpenJPA project may be found at the project web site: https://openjpa.apache.org

Upgrade Notes

Some changes of this release alter the mapping or the behaviour of existing applications. They are described in the Migration Considerations of the reference guide, together with the openjpa.Compatibility options that restore the behaviour of OpenJPA 4.1.x where one exists.

  • An AttributeConverter that declares its attribute or database type through a generic superclass or through an interface that extends AttributeConverter now maps its attribute to a column of the converter's database type. Before, such an attribute was mapped as a serialized object (a BLOB, BYTEA on PostgreSQL). Such converters, and those of a parameterized attribute type, are now also registered when they are declared autoApply, so attributes of their type get the converter and its column type. Applications with such converters need to migrate the affected columns and their data, or set openjpa.Compatibility=ResolveConverterTypeHierarchy=false to restore the 4.1.x mapping (OPENJPA-2944).

Prerequisites

OpenJPA requires Java 17 or higher and a relational database of some sort.
